# Catalogo

Status: futuro.

Ainda nao existe catalogo online oficial com links diretos de produto.

Regras:

- nao usar esta pasta para prometer disponibilidade;
- nao usar esta pasta para prometer preco;
- nao usar esta pasta para prometer estoque;
- nao inventar URL de produto;
- criar `catalogo/*.jsonl` somente quando houver fonte oficial: loja online, API, feed, planilha controlada ou cadastro validado.

Enquanto o catalogo oficial nao existir, a Lara deve usar `knowledge/produtos_genericos.jsonl` para falar apenas de categorias e conduzir para especialista ou agendamento.
